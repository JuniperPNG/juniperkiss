## Stack

Static HTML generated by [Jekyll](https://jekyllrb.com/), hosted on GitHub Pages,
written in a text editor and deployed by `git push`. No database, no CMS, no
build tooling beyond Jekyll itself, no JavaScript framework. The only script on
the site is a 30-line mobile menu toggle.

Everything is first-party by default: no Google Fonts, no CDN, no analytics.
The CV page has a handful of click-to-load YouTube videos, but nothing is
requested from YouTube until you press play. That keeps the site fast on a
poor connection and means no visitor data leaves the server without your say-so.

## Architecture

Following the Kew design system pattern: a single central token file is the
source of truth, and the stylesheet consumes it. Nothing is hard-coded.

| File | Role |
| --- | --- |
| [`assets/css/tokens.css`]({{ '/assets/css/tokens.css' | relative_url }}) | Colour, type scale, spacing, motion, target sizes |
| [`assets/css/site.css`]({{ '/assets/css/site.css' | relative_url }}) | Reset, base, layout, components, utilities |
| `_data/cv.yml` | The CV, as structured data |
| `_data/assignments.yml` | Assignments, marks and feedback |
| `_includes/bramble.html` | The bramble cane motif |
| `_includes/flag.html`, `_includes/topic-icon.html` | Inline SVG flags and topic icons |

Kew's rhythm is kept: a 4px accent rule at the top of the masthead, a 1600px
maximum page width, and 112px horizontal padding collapsing to 32px at 1024px
and 16px at 768px.

## Colour

The palette is **viridis**, the perceptually uniform colour map used in
scientific plotting. It is colour-vision-deficiency safe by construction, which
is the reason it exists.

Viridis has one hard constraint for interface use: only the dark end has enough
luminance contrast for text. The tokens file states this explicitly rather than
leaving it to judgement.

| Token | Hex | Contrast on white | Permitted use |
| --- | --- | --- | --- |
| `--v-900` | `#440154` | 15.1:1 | Any text, deep surfaces |
| `--v-800` | `#482878` | 11.6:1 | Any text |
| `--v-700` | `#3e4a89` | 8.5:1 | Any text |
| `--v-600` | `#31688e` | 6.0:1 | Body text, links, rules |
| `--v-500` | `#26828e` | 4.6:1 | Large text, borders, icons |
| `--v-400` | `#1f9e89` | 3.2:1 | Graphics and UI boundaries only |
| `--v-300` | `#35b779` | 2.5:1 | Decorative fills only |
| `--v-200` | `#6dcd59` | 1.9:1 | Decorative fills only |
| `--v-100` | `#b4de2c` | 1.6:1 | Decorative; text on deep purple |
| `--v-050` | `#fde725` | 1.2:1 | Focus halo; fills with dark text |

The full ramp appears exactly once as a continuous object: the bramble gradient.

## Typography

A system font stack led by Roboto (Kew's face, and present on Android), falling
back through Segoe UI and the platform UI font. Nothing is downloaded.

The scale is fluid, using `clamp()` between a 320px and a 1600px viewport, so
type never needs a media query and always respects the user's root font size.
Line length is capped at 68 characters.

## The bramble

A bramble cane, drawn as a botanical illustration in SVG, runs down the left of
every page: an arching stem with hooked prickles, palmate five-leaflet leaves,
a five-petalled flower and a cluster of drupelets. It is stroked with a viridis
gradient.

Brambles were my undergraduate research subject — my supervisors told me not to
work on them, so of course I did. *Rubus fruticosus* is an aggregate of hundreds
of microspecies that refuse to sit neatly in the boxes taxonomists built for
them. It seemed like the right thing to have growing behind the page.

Where the browser supports scroll-driven animation, the illustration is revealed
from the base upwards with a `clip-path` as you read, so the cane appears to
grow. Where that is unsupported, or where the visitor has asked for reduced
motion, it is simply drawn in full and stays still. Below 1200px it is dropped
entirely, to keep mobile page weight down.

It is decorative. It is `aria-hidden`, `focusable="false"` and `role="presentation"`,
and no information on this site depends on seeing it.

## Flags and icons

Country flags and topic icons on the CV are hand-drawn inline SVG, not emoji.
Emoji flags fail on Windows, which renders them as bare letter pairs, so they
are not a dependable way to label anything. Both are `aria-hidden`: every flag
and icon sits next to a text label that carries the actual meaning.

## Accessibility

Built to WCAG 2.2 level AA. The reasoning, the legal context for the UK, EU and
Australia, and the known limitations are in the
